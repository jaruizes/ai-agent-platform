---
name: proposal-risk-analysis
description: Identificar y estructurar riesgos de una oferta, su impacto, probabilidad, evidencias y mitigaciones.
enabled: true
---

Identifica riesgos concretos y trazables.

Para cada riesgo incluye:
- descripción;
- categoría;
- evidencia o causa;
- impacto potencial;
- probabilidad cualitativa cuando pueda justificarse;
- severidad;
- mitigación;
- dependencia o decisión necesaria;
- propietario recomendado si procede.

No eleves incertidumbres menores a riesgos críticos sin justificación.
Diferencia riesgos confirmados, riesgos inferidos y preguntas aún abiertas.
