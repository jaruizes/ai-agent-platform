Analiza las necesidades de integración y define una estrategia coherente.

Considera:
- APIs síncronas;
- eventos y mensajería;
- integración batch;
- CDC;
- sistemas legacy;
- contratos y versionado;
- idempotencia;
- consistencia y transacciones distribuidas;
- seguridad;
- observabilidad;
- gestión de errores y reintentos;
- límites de responsabilidad entre dominios;
- anti-corruption layers cuando proceda.

Justifica cada patrón a partir del problema y evita introducir complejidad innecesaria.
